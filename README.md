# MacKeyMap

MacKeyMap is a macOS menu bar utility for making an external Windows-layout keyboard behave like a Mac keyboard with system-level remapping and very low overhead.

## What is in this repo

- `rust-core/`: low-level Rust engine for `IOHIDManager` discovery, per-device selection, and `hidutil`-backed system remapping.
- `App/Sources/MacKeyMapApp/`: AppKit menu bar app that controls the Rust engine, persists config, and manages the menu bar UI.
- `scripts/build_app.sh`: local build script that produces `dist/MacKeyMap.app`.

## Build

```bash
./scripts/build_app.sh
```

Release build:

```bash
./scripts/build_app.sh release
```

Release zip:

```bash
./scripts/package_release.sh
```

## Run in development

```bash
cargo build --manifest-path rust-core/Cargo.toml
swift run MacKeyMapApp
```

## CI/CD

- CI runs on every push, pull request, and manual dispatch using `macos-14`.
- CI validates the Rust workspace with `cargo test --workspace`, runs the remap payload benchmark, builds the release `.app`, and uploads `MacKeyMap-macos.zip` as an artifact.
- CD runs on version tags matching `v*`.
- The release workflow rebuilds on macOS, packages `dist/MacKeyMap.app`, and publishes `MacKeyMap-macos.zip` to a GitHub Release with autogenerated notes.
- The current GitHub release artifact is unsigned or ad hoc signed on CI. For public distribution without Gatekeeper friction, add a later signing/notarization workflow backed by your Apple Developer credentials and secrets.

## Architecture

- `IOHIDManager` is used for keyboard discovery, hot-plug handling, and per-device state.
- Actual key remapping is applied through `hidutil` `UserKeyMapping`, so the system HID layer performs the remap directly.
- The built-in keyboard is detected but not auto-enabled.
- Newly discovered external keyboards are auto-enabled unless explicitly disabled in the config.

## Notes

- The app requires Input Monitoring permission to listen to HID keyboard traffic.
- The app does not post synthetic key events or depend on Accessibility permission.
- Launch-at-login registration works when the app is run from a real `.app` bundle.
- GitHub Actions CI runs Rust tests, logs the hot-path benchmark, and builds a macOS app artifact.
- GitHub Actions release packaging publishes an unsigned `MacKeyMap-macos.zip` on `v*` tags.
